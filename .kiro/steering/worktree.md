## Virtual Environment

1. ALWAYS ensure you are working on an activated virtual environment
2. run source .venv/bin/activate to activate the python virtual environment.

## Working Branch
1. ALWAYS ensure you are working in a feature branch or worktree other than `main` or `master`.
2. If a feature branch has not been activated, search for a suitably named existing branch.
3. If one does not exist, ask the user for directions before proceeding to alter any files.
